# How Agents Work

Agents operate by resolving intents and selecting workflows.

## Execution Flow
1.  **Intent Resolution**: Determine what the user wants.
2.  **Workflow Selection**: Choose the appropriate workflow.
3.  **Context Snapshot**: Build the necessary context.
4.  **MCP Tool Resolution**: Identify required tools.
5.  **Sandbox Allocation**: Provision a sandbox.
6.  **Execution**: Run the logic.
7.  **Artifact Extraction**: Retrieve results.
8.  **Context Update**: Save the new state.
9.  **Teardown**: Clean up resources.
